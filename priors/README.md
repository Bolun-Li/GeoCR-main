# GeoCR priors

Place the downloaded CPE prior files in this directory. For example:

```text
priors/
└── RUOD/
    ├── prompt_index.jsonl
    ├── emb_p3.npy
    ├── emb_p4.npy
    ├── emb_p5.npy
    ├── v_diff_embeddings.npy
    └── global_embeddings.npy
```

The generated `.npy` and `.jsonl` prior files are local data and are not tracked by this repository.
See the main [README](../README.md#cpe-priors) for download links and configuration instructions.
